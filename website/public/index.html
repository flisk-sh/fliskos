Download for macOS

Do this:

  1. Open Terminal: press ⌘ Space, type Terminal, press Enter.
  2. Paste with ⌘ V and press Enter. The app installs and opens.
curl -fsSL https://os.flisk.si/install.sh | sh

Run it again any time to update. macOS blocks apps downloaded in a browser that Apple has not approved, so the app installs from Terminal instead. Read the script.

Prefer the zip?

Download FliskOS-macOS.zip. After you move it to Applications, run this once:

xattr -cr /Applications/FliskOS.app

FliskOSLive demo

That is the real FliskOS, running on sample projects. Press Start, open a thread, ask an agent something.

Your whole stack, at a glance

Health, resources, logs, endpoints and port conflicts for every Flisk project it finds. Start, stop or restart a project, a stack or a single resource.

Bring your own login

FliskOS never asks for an API key. Each agent runs in the project folder on the login you already have, up to four at once, and you choose per thread whether it can edit.

Find out what broke, then ask

A doctor score for each project, with the warnings that cost it points. From the logs, Ask an agent opens a thread with the output already in the prompt and secret-looking values redacted.

The rest of Flisk, built in

Pages, Citable, Helpdock, the Command Comparer, the DevEx Roadmap and Demos, pointed at the project you pick. Links open in your browser. Commands are copied, never run.

$ fliskos --no-open
FliskOS is running at http://127.0.0.1:52841/?token=••••
Press Ctrl+C to close the local command center.

It lives on your machine

  • Binds only to 127.0.0.1, with a random token for each session.
  • No account and no hosted control plane.
  • A native window of about 1 MB, not Electron.
  • MIT licensed, so you can read it and change it.

Put your agents next to your stack.

Two commands. The first installs the Flisk CLI that FliskOS drives, and you can skip it if you have one.

macOS

curl -fsSL https://flisk.sh/install.sh | sh
curl -fsSL https://os.flisk.si/install.sh | sh

Windows, in PowerShell

irm https://flisk.sh/install.ps1 | iex
irm https://os.flisk.si/install.ps1 | iex

FliskOS also needs Node.js 22.12+ or Bun. On Linux, run it from a checkout.
