Your projects and coding agents in one window.

FliskOS shows every Flisk project on your Mac, starts and stops its stack, and runs Claude Code, Codex and others right next to it. It runs on your machine and holds no keys or accounts.

Download for macOSFree · Apple Silicon and Intel · macOS 12+

Do this:

  1. Open Terminal: press ⌘ Space, type Terminal, press Enter.
  2. Paste with ⌘ V and press Enter. The app installs and opens.
curl -fsSL https://os.flisk.si/install.sh | sh

Run it again any time to update. macOS blocks apps downloaded in a browser that Apple has not approved, so the app installs from Terminal instead. Read the script.

Prefer the zip?

Download FliskOS-macOS.zip. After you move it to Applications, run this once:

xattr -cr /Applications/FliskOS.app

Needs the Flisk CLI and Node.js 22.12+ or Bun.

Every project, at a glance

Health, resources, logs, endpoints and port conflicts for every Flisk project it finds. Start, stop or restart a project, a stack or one resource, and open its folder or a terminal.

Local, and only local

  • The server binds only to 127.0.0.1, with a random token for each session.
  • It never asks for an API key. There is no account and no hosted control plane.
  • A native window of about 1 MB, not Electron.
  • MIT licensed. Read the source.

What you need

FliskOS drives the Flisk CLI, so install that first. The script never runs sudo.

curl -fsSL https://flisk.sh/install.sh | sh

Then install FliskOS. You also need Node.js 22.12+ or Bun on your login shell's PATH.

curl -fsSL https://os.flisk.si/install.sh | sh

On Linux or from a checkout, run it with Node or Bun.
